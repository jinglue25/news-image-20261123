A deterministic 1024×1024 newspaper front page presenting five world stories with original geometric pictograms.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Run `python3 draw.py` to regenerate the image with Python 3, Pillow and the system Noto fonts.
